# BOOMER-OFF ERP 会员管理设计规格

## 目标

在 ERP 中建立会员主档与运营管理入口。ERP 是会员方案、有效权益、积分、优惠券、识别额度和消费记录的唯一管理界面；App 只读取会员数据，有赞只执行渠道权益并回传结果。

## 导航与页面

- 左侧导航：`运营 / 会员管理`，路由 `/operations/members`。
- 页面一级标签：会员列表、会员方案、优惠券、积分账本、消费记录、变更审计。
- 首屏总览：会员总数、探索会员数、7 天内到期、今日识别、待使用优惠券。
- 会员列表支持手机号、昵称、会员编号搜索，以及等级、状态筛选。
- 点击会员打开右侧详情抽屉，不压缩主列表。

## 会员详情

- 展示会员编号、手机号、等级、有效期、来源、自动续费状态。
- 展示可用积分、可用优惠券、今日识别额度。
- 支持查看权益、消费、积分、优惠券和操作记录。
- 支持调整会员等级/有效期、积分和补发优惠券。

## 权限与审计

- 已登录 ERP 用户可查看会员管理页面。
- 人工调整仅 `super_admin` 可执行。
- 每次调整必须包含非空原因，可选关联订单或工单号。
- 调整通过数据库 RPC 在单事务中写业务账本和 `commerce_membership_admin_audit_logs`。
- 审计记录保存操作人、动作、对象、调整前后值、原因、关联单号、幂等键与时间；不可从 ERP 修改或删除。

## 状态

- 列表和详情具备加载、空数据、错误重试状态。
- 人工调整具备校验、二次确认、提交中、防重复提交、成功刷新和失败提示。
- 搜索和筛选只影响列表，不修改会员数据。

## 视觉

- 沿用 ERP 现有 `PageHeader`、Card、Table、Tabs、Dialog 和 BOOMER-OFF 红/深蓝色系统。
- 数据总览采用深蓝运营卡；危险或人工账务动作使用红色主按钮和明确审计提示。
- 桌面宽屏使用表格；详情使用右侧抽屉，避免挤压表格列。
