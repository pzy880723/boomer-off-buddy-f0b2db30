## Remaining Gates

1. Do not install/distribute build 57 as a finished privacy rollout against this
   intermediate backend. In particular, the old smart-create worker still lacks
   the new consent enforcement and fingerprint handling. A client-side denial
   alone is not a server-side guarantee.
2. The next rollout must attach all server guards, cover manual-listing/background
   AI behavior, update the actual iPhone and Android clients, and verify real
   grant/revoke behavior. Never create implicit consent for legacy devices.
3. Current native API base URLs are fixed to production. A separate fixed
   review-backend binary is not a substitute for a usable production binary.
4. Lovable's read-only report found only headquarters-admin roles and no isolated
   review account/environment. Do not submit the actual owner account to App Review,
   create fake production stock, or import customer data into a review environment.
5. Full core screenshots, formal privacy policy, filing proof, and submission
   remain unfinished. No Apple review submission occurred.

## Rollback

Use the existing release-switch procedure as the `ubuntu` PM2 owner. Restore
`boomer-off-buddy` to the retained rollback directory with the same runner and
host-owned worker settings, check port 3005 readiness and public login/worker
checks, restore `/var/www/boomer-erp/current`, then save PM2. Do not run the old
retouch rollback script: it expects its own release to still be `current`.

Rollback only the application release; do not automatically drop shared consent
tables or migration 0047. The additive database objects remain compatible with
the previous application. Preserve any employee decisions recorded meanwhile.
