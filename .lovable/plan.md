## 问题
1. 顶部条只显示订单号+状态+门店+金额+时间，但下面又铺了商品缩略图；用户觉得"上面为啥出现这么多玩具玩偶"——其实是因为**当只有 1 件商品时，顶部条右侧的商品名/图 与 下方商品区重复**（或视觉上过于接近）。需要顶部条只承载"元数据"，商品只在下方出现一次。
2. 顶部条和商品区没有色差，看不出层次。
3. 订单之间只用 `divide-y` 分隔线，挤在一起，缺少呼吸。

## 新版式

```text
┌──────────────────────────────────────────────────┐
│░#E20250702001234  [已支付]  交易号 2024xxxx      │ ← 灰底头部（bg-muted/40）
│░BoomerOff·大阪店                  ¥1,280  07-02 │
├──────────────────────────────────────────────────┤
│ [img] 皮卡丘毛绒公仔 ················· ×2         │ ← 白底商品区（唯一出现商品的地方）
│ [img] 熊本熊挂件 ····················· ×1         │
└──────────────────────────────────────────────────┘
  ← 卡片之间 gap-3 间距，各自 rounded-lg border shadow-sm →
┌──────────────────────────────────────────────────┐
│░#E20250702001235 ...
```

### 关键改动（只改 `src/routes/orders.shops.tsx`）

1. **列表容器**：`Card > CardContent > divide-y` 改为 `<div className="space-y-3">`，每个 `OrderRow` 自带 `rounded-lg border bg-card shadow-sm overflow-hidden`。移除外层 `Card` 包裹，避免双层边框。

2. **顶部条（头部）**：
   - 背景 `bg-muted/40`，与商品区白底形成灰度对比。
   - 左侧一行：`#订单号` + 状态徽章 + `交易号 xxxx`（等宽字号缩小、muted 色）。
   - 左侧第二行：门店名（xs, muted）。
   - 右侧堆叠：金额（base 加粗）+ 支付时间（11px, muted, 简化为 `MM-DD HH:mm`）。
   - 展开箭头放在最右侧独立小按钮位。
   - 整个头部 clickable（触发展开）。

3. **商品区**：
   - 只在这里出现商品（去除顶部条任何缩略图痕迹——当前代码顶部条其实没放缩略图，但因为紧邻+无色差看着像"上面也有"，加了灰底后就明确分区）。
   - `px-4 py-3 bg-card`，最多 3 行，超出 "还有 N 件…"。
   - 只有 1 件时同样只在这里展示一次。

4. **展开明细**：保留现有 `OrderDetail`，背景 `bg-muted/20`，顶部加 `border-t`。移除展开区里重复的"交易号"（已经移到顶部条），只保留商品明细行 + 运费。

5. **卡片间距**：`space-y-3` 让每单独立成块。

## 验收
- 顶部灰底、下部白底，两区一眼分辨。
- 商品只在下方出现一次，不再有"上下都是玩偶"的感觉。
- 订单号、状态、交易号在最顶部一行。
- 卡片之间有 12px 间距，不再挤成一坨。
- 不改数据源、server function、其他 tokens。
