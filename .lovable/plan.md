## 问题
有赞零售 API 对 `page_size` 有上限 20，但目前商品同步用 50、订单同步用 100、店铺列表用 200，都会触发 `[234000003] 参数错误：每页最多20个`。

## 修复
把 `src/lib/youzan.functions.ts` 中所有有赞分页请求的 `page_size` 改为 **20**：

1. 行 488（店铺列表 `youzan.shop.get`）：`page_size: 200` → `20`
2. 行 735（商品同步 `pageSize = 50`）→ `20`
3. 行 958（订单同步 `pageSize = 100`）→ `20`

循环判停逻辑（`items.length < pageSize` 退出）和 `page > 200 / > 500` 上限保持不变，只是单页变小，循环次数自然变多。

## 验证
* HQ 点"同步商品" → 期望不再出 `[234000003]`，开始正常分页入库。
* 分店点"同步订单" → 期望不再出 `每页最多20个`。
* 若再次出现 4005/4007，则属于授权/IP 白名单问题，与本次无关。
