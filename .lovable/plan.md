## 目标
把 `/orders/shops` 的列表重排，让「一行一单」看起来像专业的电商订单管理，不再是又高又挤的多列换行。

## 新样式（卡片式行，不再用宽表格）
每条订单渲染为一张卡片行（保留可展开明细），结构如下：

```text
┌────────────────────────────────────────────────────────────────────┐
│ #E20250702001234   [已支付]   门店：BoomerOff · 大阪店     ¥1,280   │  ← 顶部条
│                                                       2026-07-02 14:23│
├────────────────────────────────────────────────────────────────────┤
│ [img] 商品标题 A ················· ×2                                │
│ [img] 商品标题 B ················· ×1                                │  ← 商品区（最多显示 2-3 行，多余"共 N 件 / 展开查看"）
└────────────────────────────────────────────────────────────────────┘
```

要点：
- **订单号排最前**，等宽字体 + 可点复制样式；紧跟状态徽章。
- **门店名**放顶部条右侧，弱化字号。
- **金额 + 支付时间**右对齐堆叠。
- **商品**移到下方，多商品竖排（缩略图 40×40 + 标题 + ×数量），超过 3 行显示"还有 N 件商品"。
- **删除"买家"和"收货人"列**（门店订单没有这些字段）。
- 展开区仍显示 `OrderDetail`，但内部也去掉"收货"面板（保留商品明细 + 支付/交易号 + 运费）。

## 交互
- 整卡点击展开/收起（沿用 `expandedId`）。
- 右上角保留一个小 `ChevronDown/Right` 指示。
- 分页、筛选、header 统计不变。

## 实现范围
- 只改 `src/routes/orders.shops.tsx`：
  - 用 `<div>` 卡片列表替换现有 `<table>`（保留 `Card`/`CardContent` 外框，用 `divide-y`）。
  - 卡片渲染函数抽成局部 `OrderRow` 子组件。
  - 移除表头及买家/收货人列。
  - `OrderDetail` 中删除"收货"块，商品明细区跨满宽度。
- 不改数据源、不改 server function、不改样式 tokens 之外的东西。

## 验收
- 一行卡片总高度 ~90–110px（当前多列换行普遍 140px+）。
- 订单号在最显眼位置；门店订单没有"买家/收货人"字样。
- 展开后能看到商品明细和支付信息，但不再出现"收货"块。
